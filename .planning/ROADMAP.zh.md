# 路线图：Portunity

**项目：** Windows 端口管理工具（双前端：Tauri GUI + Ratatui TUI）
**核心价值：** 瞬间找到、分类并操作任何活跃端口及其所属进程 —— 从发现到执行，零摩擦。
**创建日期：** 2026-07-26
**粒度：** Standard（6 个阶段）
**模式：** mvp（每个阶段交付端到端用户可见能力）
**里程碑：** 1（所有 v1 功能在一个里程碑内）

## 阶段

- [ ] **Phase 1: TUI 端口查看器** — 用户启动终端应用，查看实时、可排序、可过滤的 TCP/UDP 端口表及进程详情，连接状态颜色编码。管理员可提权。
- [ ] **Phase 2: 进程管理与智能终止** — 用户查看任意端口进程的完整详情，使用智能终止升级和白名单保护终止进程。
- [ ] **Phase 3: 实时监控与历史** — 端口列表通过 ETW 自动更新；用户通过迷你趋势图监控每端口流量速率，浏览端口占用变化历史时间线。
- [ ] **Phase 4: 防火墙管理与导出** — 用户管理 Windows 防火墙规则（查看、创建、删除、启用/禁用），右键快捷操作，导出 JSON/CSV/剪贴板。
- [ ] **Phase 5: 桌面 GUI** — 用户拥有原生 Windows 桌面应用（Tauri+Svelte），响应式端口表格、系统托盘集成、Phase 1-4 全部能力融入精致 UI。
- [ ] **Phase 6: 打磨 — 标签、收藏、主题与国际化** — 用户享受自动标注的常用端口、自定义标签、收藏夹、6 套可切换视觉主题、中英文语言切换。

## 阶段详情

### Phase 1: TUI 端口查看器
**目标：** 用户可启动终端应用，查看所有活跃 TCP/UDP 端口的实时、可排序、可过滤表格，含所属进程详情，连接状态颜色编码。管理员权限自动检测并在需要时提供提权。
**模式：** mvp
**依赖：** 无（首个阶段）
**需求：** CORE-01, CORE-02, CORE-04, CORE-05, CORE-06, SCAN-01, SCAN-02, SCAN-03, SCAN-04, SCAN-06, SCAN-07, TUI-01, TUI-02, TUI-03, TUI-04, TUI-07, TUI-08, SRCH-01, SRCH-03（19 项）
**成功标准：**
  1. 用户在 80x24 或更大终端中启动 `port-tui`，看到所有活跃 TCP（含连接状态）和 UDP 端口的表格，每个端口显示所属进程名和 PID
  2. 连接状态通过颜色区分（LISTENING=绿、ESTABLISHED=蓝、TIME_WAIT=灰、CLOSE_WAIT=黄），可按任意列表头排序，排序状态在手动刷新间保持
  3. 用户按 `/` 打开模糊搜索栏；输入时端口表格实时过滤，匹配所有字段
  4. 用户可应用组合过滤（端口号范围、进程名子串、PID、协议、连接状态），结果即时更新
  5. 无管理员权限运行仍可只读查看所有端口，系统进程有明确限制标记；自动检测需要管理员权限时提供 UAC 提权提示
**计划：** 待定
**UI 提示：** 有

### Phase 2: 进程管理与智能终止
**目标：** 用户可查看任意端口所属进程的详细信息，使用智能终止升级（优雅关闭→超时→强制终止）结束进程，白名单保护防止误杀系统关键进程。
**模式：** mvp
**依赖：** Phase 1（端口列表提供选择目标；扫描器提供 PID→进程映射）
**需求：** PROC-01, PROC-02, PROC-03, PROC-04, PROC-05, PROC-06, PROC-07, SRCH-02（8 项）
**成功标准：**
  1. 用户选中端口查看其所属进程详情：完整可执行文件路径、启动时间、命令行参数、数字签名状态、父进程 PID —— 全部展示在专用详情面板中
  2. 用户一键（`k`）终止进程；非白名单进程即时终止，白名单进程弹出确认对话框说明保护原因
  3. 终止进程时优先尝试优雅关闭（GUI 进程 WM_CLOSE），等待可配置超时，无响应则强制终止 —— 结果（成功或失败原因）清晰显示
  4. 用户无法意外终止系统关键进程（smss.exe、csrss.exe、lsass.exe、svchost.exe 等）—— 尝试终止受保护进程时显示清晰易懂的说明
  5. 用户可在设置中添加或删除进程到保护白名单；白名单更改即时生效无需重启
**计划：** 待定
**UI 提示：** 有

### Phase 3: 实时监控与历史
**目标：** 端口列表随连接创建、关闭或状态变化自动更新。用户通过迷你趋势图监控每端口流量速率，浏览可搜索的端口占用事件时间线。ETW 事件驱动刷新消除空闲时 CPU 消耗；2s 轮询兜底 UDP 和边界情况。
**模式：** mvp
**依赖：** Phase 1（端口扫描器基础）、Phase 2（PID 处理模式确保事件处理安全）
**需求：** SCAN-05, CORE-03, TRAF-01, TRAF-02, TRAF-03, HIST-01, HIST-02, HIST-03, HIST-04（9 项）
**成功标准：**
  1. 端口列表在连接创建、关闭或状态变化时自动更新 —— 无需手动刷新；状态栏显示"Live (ETW)"或自动刷新指示器及最后更新时间戳
  2. 用户打开流量 Tab（Tab 4），看到每端口/每进程的收发字节数，附带显示近期速率趋势的迷你趋势图
  3. 用户打开历史 Tab（Tab 3），浏览可搜索的端口占用事件时间线 —— 哪个端口被占用、释放或变更，哪个进程，什么时间
  4. 用户可按端口号、PID、进程名或日期范围查询历史，时间线显示过滤结果
  5. 超过配置保留期（默认 30 天，可在设置中配置）的历史条目自动清理，控制存储增长
**计划：** 待定
**UI 提示：** 有

### Phase 4: 防火墙管理与导出
**目标：** 用户管理 Windows 防火墙规则（查看、创建、删除、启用/禁用），右键快捷操作创建合理默认值，从 TUI 导出当前端口列表为 JSON、CSV 或剪贴板文本 —— 管理员提权自动提示。
**模式：** mvp
**依赖：** Phase 1（基础+Tab 基础设施）、Phase 2（管理员提权模式）
**需求：** FW-01, FW-02, FW-03, FW-04, FW-05, FW-06, EXP-01, EXP-02, EXP-03（9 项）
**成功标准：**
  1. 用户打开防火墙 Tab（Tab 5），浏览、过滤和排序所有 Windows 防火墙规则（入站/出站、允许/阻止、按端口、按程序路径）
  2. 用户创建新防火墙规则（指定名称、方向、动作、协议、本地端口、程序路径）；删除用户创建的规则；一键切换任意规则的启用/禁用状态 —— 需管理员权限操作自动提示 UAC 提权，拒绝时显示清晰失败信息
  3. 用户右键端口列表任意条目，选择"在防火墙中阻止此端口"或"在防火墙中放行此端口"—— 一键创建具备合理默认值的防火墙规则
  4. 用户导出当前端口列表为 JSON（结构化，含 schema 版本）或 CSV（电子表格兼容，含列标题），复制选中行为制表符分隔文本
  5. 导出数据与可见的过滤端口列表完全一致 —— 所见即所得
**计划：** 待定
**UI 提示：** 有

### Phase 5: 桌面 GUI
**目标：** 用户启动原生 Windows 桌面应用（Tauri v2+Svelte），拥有响应式端口表格、系统托盘集成（带迷你端口列表的悬浮面板、快捷操作菜单），Phase 1-4 全部能力通过精致 Svelte UI 可用，无需接触终端。
**模式：** mvp
**依赖：** Phase 1-4（所有 port-core API 需经 TUI 实战检验后方可被 GUI 封装）
**需求：** GUI-01, GUI-02, GUI-03, GUI-04（4 项）
**成功标准：**
  1. 用户启动桌面应用，看到与 TUI 功能匹配的响应式端口表格，鼠标和键盘均可排序、过滤、搜索
  2. 用户可通过 Svelte UI 管理防火墙规则、查看流量图表（速率曲线替代迷你趋势图）、浏览历史时间线、导出数据 —— 无需使用 TUI
  3. 应用打开时系统托盘图标可见；右键显示设置、打开窗口、退出；左键打开悬浮面板含迷你端口列表+快速搜索；双击打开主窗口
  4. 关闭主窗口行为可在设置中配置（最小化到托盘或完全退出）；管理员操作（终止、防火墙）自动检测并提示 UAC 提权，附带清晰易懂的说明
  5. 所有数据从 port-core 流到 Svelte UI 通过响应式 stores 自动更新 —— 前端无需手动轮询
**计划：** 待定
**UI 提示：** 有

### Phase 6: 打磨 — 标签、收藏、主题与国际化
**目标：** 用户享受自动标注的常用开发端口（PostgreSQL、Redis、Next.js 等），可分配自定义可搜索标签，收藏常用端口快速访问，即时切换 6 套视觉主题，中英文界面切换，所有字符串外置到共享 Fluent FTL 文件。
**模式：** mvp
**依赖：** Phase 1-5（所有功能必须存在后方可打磨 —— 标签和收藏是端口列表上的叠加层；主题和国际化触及所有 UI 表面）
**需求：** SRCH-04, SRCH-05, SRCH-06, TUI-05, TUI-06, GUI-05, GUI-06, I18N-01, I18N-02, I18N-03（10 项）
**成功标准：**
  1. 用户看到常用开发端口自动标注（5432→PostgreSQL、3306→MySQL、6379→Redis、3000→Next.js、5173→Vite、8080→HTTP Dev 等），无需任何配置 —— 标签排在端口表格内
  2. 用户通过右键或键盘快捷键为任意端口分配自定义标签（"我的开发服务器"、"生产数据库隧道"）；自定义标签与自动标签一视同仁可搜索
  3. 用户收藏端口（星标/收藏）；收藏端口作为常驻侧边栏或过滤预设出现，一键访问
  4. 用户在 TUI 中按 `t` 键或在 GUI 设置中选择，循环切换 6 套预设主题（One Dark、Dracula、Solarized、Nord、Monokai、High Contrast）；主题即时应用至所有 UI 表面
  5. 用户在 TUI 中按 `l` 键或在 GUI 设置中切换中英文；所有标签、标题、消息和 UI 文本即时切换语言，首次启动时从系统语言自动检测
