# 第一阶段 — UI 设计契约 (TUI)

> 基于终端的端口查看器的视觉与交互契约。由 gsd-ui-researcher 生成，针对 TUI 场景（Ratatui + crossterm）适配。经 gsd-ui-checker 验证。

## 设计系统

| 属性 | 值 |
|----------|-------|
| 框架 | Ratatui 0.30.2 |
| 后端 | crossterm 0.29.0 |
| 控件库 | eddacraft-tui 0.4.0 (DataTable 用于端口列表), ratatui-widgets 0.7.10 |

## 布局与间距

终端渲染使用固定的字符单元格网格。布局约束以行、列和百分比比例表示，而非像素。Ratatui `Constraint` 枚举定义布局引擎。

### 面板布局（所有标签页通用）

```
┌─ 标签栏 ──────────────────────────────────────────┐   第 0 行: 1 行
│ [1] 概览  [2] 端口  [3] 历史  [4] 流量…           │
┡━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┩
│                                                     │   第 1..(N-3) 行:
│               内容区域                              │   剩余空间
│       （每个标签页的控件，参见控件清单）             │
│                                                     │
├─ 状态栏 ────────────────────────────────────────────┤   第 (N-2) 行: 1 行
│ 实时 · 847 个端口 · 管理员 ✓ · 12:34:56            │
├─ 页脚 ─────────────────────────────────────────────┤   第 (N-1) 行: 1 行
│ [1-5]标签 [Tab]聚焦 [/]搜索 [f]过滤 [r]刷新        │
└─────────────────────────────────────────────────────┘
```

### 布局约束

| 区域 | 约束 | 窗口大小变化时行为 |
|--------|-----------|-------------------|
| 标签栏 | `Length(1)` | 固定 1 行 |
| 内容区域 | `Min(20)` 按比例填充 | 随终端扩展/收缩 |
| 状态栏 | `Length(1)` | 固定 1 行 |
| 页脚 | `Length(1)` | 固定 1 行 |
| 帮助叠加层 | 居中弹出，60 列 x 20 行，`Clear` 背景 | 固定大小，居中 |
| 搜索栏 | 内容区域顶部 `Length(3)` 弹出层 | 内容区域全宽 |
| 过滤面板 | 搜索栏下方 `Length(5)` 内联面板 | 可见时固定 5 行 |

### 最小尺寸限制

| 条件 | 行为 |
|-----------|----------|
| 终端 < 80x24 | 渲染居中消息："终端太小。最低要求：80x24。当前：{宽}x{高}" |
| 终端 >= 80x24 | 完整布局按比例渲染 |

### 列布局（端口表格）

当内容区域宽度 >= 80 列时，端口表格渲染所有列。低于 80 列时，按优先级折叠列：

| 优先级 | 列名 | 最小宽度 | 折叠阈值 |
|----------|--------|-----------|----------------|
| 1（保留） | 状态指示器 | 1 | 永不折叠 |
| 2（保留） | 端口 | 8 | 永不折叠 |
| 3（保留） | 协议 | 4 | 永不折叠 |
| 4 | 进程名称 | 12 | 60 列 |
| 5 | PID | 6 | 50 列 |
| 6 | 本地地址 | 18 | 40 列 |
| 7 | 远程地址 | 18 | 40 列 |

**来源：** REQUIREMENTS.md 中的 TUI-07（最低 80x24，窗口变化时优雅降级）；列优先级来自 SCAN-01、SCAN-02。

## 排版

终端模拟器使用由用户终端设置决定的单一等宽字体。应用程序无法控制字体族、大小或行高。**所有文本均为等宽字体。所有单元格宽度相等。**

### 文本修饰符（唯一可用的排版手段）

| 修饰符 | SGR 码 | 用途 |
|----------|----------|-------|
| **粗体** | SGR 1 | 列标题、标签页标签（激活状态）、章节标题、状态栏标签 |
| **暗淡** | SGR 2 | 元数据（时间戳、PID、进程 ID）、次要信息、非激活标签页标签 |
| _斜体_ | SGR 3 | 第一阶段不使用（终端支持不一致）。保留用于第六阶段标签。 |
| 下划线 | SGR 4 | 页脚和帮助叠加层中的交互/快捷键字符 |
| 反转 | SGR 7 | 选中行高亮（主要选中指示器） |
| 删除线 | SGR 9 | 第一阶段不使用。保留用于第二阶段已终止进程。 |

### 视觉层级

| 角色 | 修饰符 | 颜色槽 | 示例 |
|------|----------|------------|---------|
| 标签页标签（激活） | 粗体 + 反转 | `accent.primary` 背景色 | **[2] 端口** |
| 标签页标签（非激活） | 暗淡 | `fg.muted` | [1] 概览 |
| 列标题 | 粗体 | `fg.emphasis` | **状态  端口  PID  进程** |
| 选中行 | 反转 | `bg.selection` | 整行反色 |
| 端口号 | 无 | `fg.default` | 8080 |
| 进程名称 | 无 | `fg.default` | nginx.exe |
| 时间戳 | 暗淡 | `fg.muted` | 12:34:56 |
| 状态栏标签 | 粗体 | `fg.muted` | **实时** |
| 状态栏数值 | 无 | `fg.default` | 847 个端口 |
| 过滤输入提示 | 粗体 | `accent.primary` | **/>_** |
| 帮助快捷键标签 | 粗体 + 下划线 | `accent.primary` | **q** |

**来源：** TUI-07（终端固有的等宽约束）；层级模式来自 tui-design skill。

## 颜色

### 主题：One Dark（第一阶段默认）

第一阶段使用基于 One Dark 的单一硬编码深色主题。主题系统（6 套预设、TOML 文件、`t` 键切换）为第六阶段内容。尚无面向用户的主题选择；所有颜色值均为编译时常量。

### 语义颜色槽

颜色由语义角色定义，而非十六进制值。实现将槽映射到终端颜色（256 色调色板，支持 16 色 ANSI 回退）。检测：`$COLORTERM` → 优先真彩色；`$NO_COLOR` → 单色模式（禁用所有颜色，仅布局 + 反转）。

| 槽 | 256 色 | 真彩色 (hex) | ANSI 回退 | 用途 |
|------|-----------|-------------------|---------------|---------|
| `fg.default` | 252 | `#abb2bf` | 白色 | 正文、端口号、进程名称 |
| `fg.muted` | 241 | `#5c6370` | 亮黑色 | 元数据、时间戳、非激活标签页、TIME_WAIT 状态 |
| `fg.emphasis` | 255 | `#e5e5e5` | 亮白色 | 列标题、章节标题 |
| `bg.base` | 234 | `#1a1b26` | 黑色 | 主背景 |
| `bg.surface` | 235 | `#24283b` | 黑色 | 面板背景、表格行（奇数行） |
| `bg.overlay` | 236 | `#2c3043` | 黑色 | 搜索栏、过滤面板、帮助叠加层背景 |
| `bg.selection` | 237 | `#364a82` | 蓝色 | 选中行背景（与反转配合） |
| `accent.primary` | 39 | `#61afef` | 青色 | 焦点指示器、搜索提示、交互提示、激活标签页边框 |
| `accent.secondary` | 170 | `#c678dd` | 洋红色 | 第一阶段不使用。保留用于第二阶段终止操作高亮。 |
| `status.success` | 42 | `#98c379` | 绿色 | LISTENING 状态、成功消息、管理员-正常指示器 |
| `status.warning` | 214 | `#e5c07b` | 黄色 | CLOSE_WAIT 状态、管理员-需要指示器、过滤激活指示器 |
| `status.error` | 203 | `#e06c75` | 红色 | 错误消息、SYN_SENT 状态、访问被拒绝指示器 |
| `status.info` | 38 | `#56b6c2` | 蓝色 | ESTABLISHED 状态、信息消息、刷新指示器 |

### 连接状态颜色映射

依据 REQUIREMENTS.md 中的 SCAN-03：

| 状态 | 颜色槽 | 视觉表现 | 理由 |
|-------|-----------|--------|--------|
| LISTENING | `status.success` | 绿色圆圈 ● | 服务就绪 — 积极/稳定 |
| ESTABLISHED | `status.info` | 蓝色圆圈 ● | 活动连接 — 中性/信息性 |
| TIME_WAIT | `fg.muted` | 灰色圆圈 ○ | 临时清理 — 低重要性 |
| CLOSE_WAIT | `status.warning` | 黄色圆圈 ◉ | 等待本地关闭 — 需要注意 |
| SYN_SENT | `status.error` | 红色圆圈 ● | 出站尝试 — 罕见，可能表示问题 |
| FIN_WAIT* | `fg.muted` | 灰色圆圈 ○ | 关闭序列 — 临时状态 |
| UDP（无状态） | `fg.muted` | 灰色横线 — | 无状态协议 — 仅供参考 |

### 主色/辅色/强调色比例（60/30/10 法则）

| 角色 | 颜色槽 | 占比 | 元素 |
|------|-----------|----------|----------|
| 主色 (60%) | `bg.base` | 背景 | 主视口、空白标签页面板 |
| 辅色 (30%) | `bg.surface`、`bg.overlay` | 面板、弹出层 | 表格行背景、搜索栏、过滤面板、帮助叠加层 |
| 强调色 (10%) | `accent.primary` | 交互焦点 | 激活标签页指示器、搜索提示光标、选中行边框、页脚快捷键提示 |

**强调色仅用于：** 激活标签页高亮、搜索/过滤输入提示、聚焦元素边框、页脚快捷键下划线以及行选中指示器。其他元素不得使用强调色。绝不应用于静态内容或正文。

### 背景层级（深度）

```
bg.base（最深）→ bg.surface → bg.overlay（最浅）
```

每级约 5-8% 亮度递增。无需厚重边框即可创建感知深度。标签栏和状态栏使用 `bg.surface` 以区别于主 `bg.base` 内容区域。

**来源：** REQUIREMENTS.md 中的 SCAN-03（连接状态颜色）；语义槽和层级来自 tui-design skill；One Dark 调色板适配自第六阶段主题列表（TUI-05）— 这是第一个预设，已转换为语义槽。

## 文案契约

### 主要行动号召
| 元素 | 文案 |
|---------|------|
| 初始启动 CTA | 无显式 CTA — 应用启动时自动扫描。首次运行空状态显示"正在扫描端口..."旋转器。 |

### 空状态

| 元素 | 标题 | 正文 |
|---------|---------|------|
| 无端口 | "没有活动端口" | "当前没有 TCP 或 UDP 端口在使用中。这种情况不常见 — 请检查网络服务是否正在运行。" |
| 搜索无结果 | "没有匹配 '{query}' 的端口" | "尝试调整搜索词，或按 Esc 清除。" |
| 过滤无结果 | "没有匹配的端口" | "没有端口匹配当前过滤条件。尝试放宽条件，或按 Esc 清除所有过滤。" |
| 未来标签页（历史/流量/防火墙） | "即将推出" | "此标签页将在后续阶段提供。按 1 或 2 查看可用标签页。" |

### 错误状态

| 元素 | 问题描述 | 下一步 |
|---------|--------------------|-----------|
| 端口扫描失败 | "扫描失败：{错误详情}" | "请检查您是否有足够的权限。按 r 重试。" |
| 管理员权限被拒绝 | "信息受限：需要管理员权限" | "部分进程信息已隐藏。请以管理员身份运行以获取完整信息。按 a 提升权限。" |
| 终端太小 | "终端太小" | "最低要求：80 列 x 24 行。当前：{宽}x{高}。请调整终端窗口大小以继续。" |
| SQLite 初始化失败 | "数据库错误：无法初始化存储" | "请检查应用数据目录的磁盘空间和写入权限。应用将以内存模式继续运行。" |

### 破坏性操作

第一阶段无破坏性操作。进程终止为第二阶段内容。管理员权限提升是唯一涉及提权的操作：

| 操作 | 确认方式 |
|--------|----------------------|
| 管理员权限提升 (UAC) | 状态栏显示"需要管理员权限以获取完整进程信息"。用户按 `a` 触发 UAC。Windows 原生处理权限提升提示。无需应用内确认对话框 — 操作系统提示即为确认。 |

### 状态栏消息

| 状态 | 消息模式 |
|-------|----------------|
| 空闲（实时） | `实时 · {N} 个端口 · 管理员 {✓/需要} · {HH:MM:SS}` |
| 扫描中 | `扫描中… · 已发现 {N} 个 · 管理员 {✓/需要} · {HH:MM:SS}` |
| 过滤激活 | `已过滤：{N} 个端口中的 {M} 个 · "{过滤描述}" · 管理员 {✓/需要}` |
| 搜索激活 | `搜索："{关键词}" · {M} 个结果` |
| 错误 | `⚠ {错误消息} · 按 r 重试` |
| 已提权（UAC 后） | `实时 · {N} 个端口 · 管理员 ✓ · {HH:MM:SS} · 完整进程信息可用` |

### 页脚（上下文感知）

默认模式（无修饰键激活）：
```
[1-5]标签 [Tab]聚焦 [/]搜索 [f]过滤 [r]刷新 [a]提权 [q]退出 [?]帮助
```

搜索模式：
```
[Esc]取消 [Enter]确认  —  跨所有字段模糊搜索
```

过滤模式：
```
[Esc]取消 [Tab]下一字段 [Enter]应用  —  按端口/PID/进程/状态/协议过滤
```

**来源：** REQUIREMENTS.md 中的 TUI-02（键盘快捷键）；页脚格式来自 tui-design skill。具体文案按第一阶段范围起草。

## 键盘契约

### 快捷键层级

依据 tui-design skill 的四层键盘模型：

**L0：全局键**（始终显示在页脚）
| 按键 | 操作 |
|-----|--------|
| `1` `2` `3` `4` `5` | 切换标签页 |
| `Tab` | 聚焦下一个面板/交互元素 |
| `Shift+Tab` | 聚焦上一个面板/交互元素 |
| `Enter` | 选择 / 确认 / 应用 |
| `Esc` | 取消 / 关闭 / 返回 |
| `q` | 退出应用程序 |
| `↑` `↓` | 在端口列表中导航行 |
| `←` `→` | 在过滤/搜索字段内导航 |

**L1：Vim 风格**（始终显示在页脚）
| 按键 | 操作 |
|-----|--------|
| `j` / `k` | 在端口列表中下移 / 上移 |
| `h` / `l` | 左 / 右（标签栏，或将来用于列折叠） |
| `/` | 打开搜索栏 |
| `?` | 打开帮助叠加层 |
| `g` / `G` | 跳转到列表顶部 / 底部 |

**L2：操作键**（显示在页脚和帮助中）
| 按键 | 操作 |
|-----|--------|
| `r` | 手动刷新（完全重新扫描） |
| `f` | 打开过滤面板 |
| `a` | 请求管理员权限提升 (UAC) |
| `s` | 切换排序列 / 循环排序顺序 |
| `Space` | 第一阶段不使用。保留用于选中切换（第二阶段）。 |

**L3：高级键**（仅在帮助叠加层中显示）
| 按键 | 操作 |
|-----|--------|
| `Ctrl+r` | 强制完全重新扫描（绕过缓存） |
| `Ctrl+f` | 切换过滤面板可见性 |
| `Ctrl+l` | 清除所有过滤和搜索 |

**永不绑定（终端保留）：** `Ctrl+C`（中断）、`Ctrl+Z`（挂起）、`Ctrl+\`（退出信号）、`Ctrl+S`/`Ctrl+Q`（流控制）。

### 焦点管理

| 状态 | 视觉指示器 | 可用按键 |
|-------|-----------------|-------------|
| 标签栏聚焦 | 激活标签页：粗体 + `bg.surface` 高亮。非激活：暗淡。 | `1-5`、`←` `→`、`h` `l` |
| 概览标签页聚焦 | 统计卡片：粗体数字作为主要视觉锚点。小型表格：进入标签页时首行自动聚焦。管理员卡片：`a` 键提示高亮。焦点循环：统计卡片 → 小型表格 → 管理员卡片。聚焦面板获得 `bg.surface` 高亮。 | `Tab` 循环面板，`↑` `↓` 在小型表格内操作 |
| 端口列表聚焦 | 单行：反色视频高亮。列标题排序指示器：排序列旁显示 `▲`/`▼`。 | `↑` `↓`、`j` `k`、`g` `G`、`Enter`（未来下钻） |
| 搜索栏聚焦 | 输入字段中闪烁光标。搜索提示：`/>_`。 | 文本输入、`Esc` 取消、`Enter` 确认 |
| 过滤面板聚焦 | 聚焦字段：`bg.overlay` + 光标。其他字段：`bg.surface`。 | `Tab` 循环字段、`Enter` 应用、`Esc` 取消 |
| 帮助叠加层（模态） | 背景变暗 + 居中弹出层。所有背景交互被阻止。 | `↑` `↓` 滚动、`Esc` 或 `?` 关闭 |

### 排序交互

| 操作 | 视觉效果 |
|--------|--------|
| 按一次 `s` | 按当前列升序排序。列标题显示 `▲`。 |
| 再按一次 `s` | 同一列降序排序。列标题显示 `▼`。 |
| 先按 `←`/`→` 再按 `s` | 移动排序列，然后排序。 |
| 在同一列上重复排序 | 循环：无 → 升序 → 降序 → 无。 |

**来源：** REQUIREMENTS.md 中的 TUI-02（键盘导航）、SCAN-04（按任意列排序）；键盘层级来自 tui-design skill。

### 各标签页组件

### DataTable 配置（用于端口标签页）

| 属性 | 值 |
|----------|-------|
| 控件 | `eddacraft_tui::DataTable` 或自定义 `VirtualTable` |
| 行渲染 | 斑马条纹：奇数行 `bg.base`，偶数行 `bg.surface` |
| 选中 | 单行，反色视频 |
| 排序指示器 | 列标题后追加 `▲`（升序）/ `▼`（降序） |
| 截断 | 在单元格边界处用 `…` 截断列内容。不换行。 |
| 滚动 | 1000+ 行时使用虚拟滚动。右侧滚动条：`│`、`░`、`█` |
| 列对齐 | 文本：左对齐。数字（端口、PID）：右对齐。状态：居中。 |
| 行高 | 每个端口条目 1 行。无多行行。 |

## 控件来源安全

不适用于 shadcn 注册表（TUI 项目）。本节适配为 TUI 控件生态系统审计。

| 控件来源 | 使用的控件 | 安全门槛 |
|---------------|-------------|-------------|
| ratatui 官方 (0.30.2) | 所有核心控件（Block、Paragraph、List、Table、Tabs、Clear、Layout、Span、Line） | 不需要 — 官方第一方 crate |
| crossterm (0.29.0) | 终端后端 | 不需要 — 官方第一方 crate |
| eddacraft-tui (0.4.0) | DataTable、Spinner | 仅视图 — crates.io 发布的 Rust crate。来源：`crates.io/crates/eddacraft-tui`。无网络访问、无环境变量读取。标准 Ratatui 控件组合。 |
| ratatui-widgets (0.7.10) | 第一阶段不使用（可用于滚动条、弹出层） | 不需要 — 官方 Ratatui 组织项目 |

**验证：** 所有控件均为 crates.io 上 Ratatui 生态内的 Rust crate。无 JavaScript、无网络访问、无环境变量访问。构建时将使用标准的 `cargo vet` 或 `cargo deny` 进行供应链安全审计。
