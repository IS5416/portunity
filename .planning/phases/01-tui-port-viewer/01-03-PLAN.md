<objective>
Add interactive filtering, fuzzy search, and admin elevation to the TUI port viewer. The user can press '/' to fuzzy-search across all port fields in real-time, press 'f' to apply combined dimension filters (port range, process name, PID, protocol, state), and press 'a' to trigger UAC elevation when running without admin rights. Non-admin users see all ports but with limited process detail for system-owned processes.

Purpose: Filtering and search are the "find" half of the core value proposition ("Instantly find, classify, and act"). Admin elevation unlocks full process detail visibility.
Output: Interactive search bar, filter panel, admin elevation flow, and non-admin graceful degradation.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| TUI → Windows ShellExecuteExW | The TUI binary calls ShellExecuteExW to relaunch itself with elevated privileges. The runas verb triggers a Windows UAC prompt — the OS mediates the elevation. The new process is a fresh instance with admin token. |
| User keyboard input → filter/search | Search query and filter values come from terminal user input. No SQL injection vector (filters operate on in-memory Vec, not SQL). No command injection (no shell commands constructed from input). |
