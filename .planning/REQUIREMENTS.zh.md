# 需求文档：Portunity

**定义日期：** 2026-07-26
**核心价值：** 瞬间找到、分类并操作任何活跃端口及其所属进程 —— 从发现到执行，零摩擦。

## v1 需求

初始版本需求。所有功能在一个里程碑内交付，按波次组织。

### 端口扫描 (SCAN)

- [ ] **SCAN-01**: 用户可查看所有活跃 TCP 端口，显示所属进程名、PID、本地地址:端口、远程地址:端口、连接状态
- [ ] **SCAN-02**: 用户可查看所有活跃 UDP 端口，显示所属进程名、PID、本地地址:端口
- [ ] **SCAN-03**: 连接状态颜色编码（LISTENING=绿色, ESTABLISHED=蓝色, TIME_WAIT=灰色, CLOSE_WAIT=黄色）
- [ ] **SCAN-04**: 用户可按任意列排序端口表格（端口号、PID、进程名、协议、状态）
- [ ] **SCAN-05**: 端口列表通过 ETW 事件刷新（TCP 连接变化）；2 秒轮询兜底 UDP 和边界情况
- [ ] **SCAN-06**: 应用自动检测是否需要管理员权限，触发 UAC 提权对话框
- [ ] **SCAN-07**: 非管理员用户可只读查看所有端口；系统进程在提权前显示有限详情

### 搜索与过滤 (SRCH)

- [ ] **SRCH-01**: 用户可按端口号（精确或范围）、进程名（子串）、PID、协议（TCP/UDP）、连接状态过滤端口
- [ ] **SRCH-02**: 用户可组合多个过滤维度，使用 AND/OR 逻辑（分面搜索）
- [ ] **SRCH-03**: 用户可通过单一文本输入跨所有字段模糊搜索（TUI 按 `/` 键，GUI 搜索栏）
- [ ] **SRCH-04**: 应用自动标注已知端口（5432→PostgreSQL, 3306→MySQL, 6379→Redis, 3000→Next.js, 5173→Vite 等）—— 约 50 个常用端口的静态映射
- [ ] **SRCH-05**: 用户可为端口自定义标签（"我的开发服务器"、"生产数据库隧道"）；标签可搜索
- [ ] **SRCH-06**: 用户可收藏/书签端口以便快速访问；收藏显示为侧边栏或过滤预设

### 进程管理 (PROC)

- [ ] **PROC-01**: 用户可从端口列表直接终止选中端口所属进程
- [ ] **PROC-02**: 智能终止：先发送优雅关闭（GUI 进程 WM_CLOSE，控制台进程 Ctrl+C），等待可配置超时，无响应则强制结束（TerminateProcess）
- [ ] **PROC-03**: 非白名单进程默认即时终止；白名单内进程终止前显示确认对话框
- [ ] **PROC-04**: 内置白名单保护约 30 个系统关键进程（smss.exe, csrss.exe, wininit.exe, services.exe, lsass.exe, svchost.exe, winlogon.exe, System, Idle 等）
- [ ] **PROC-05**: 用户可在设置中自定义白名单（按可执行文件路径添加/删除进程）
- [ ] **PROC-06**: 用户可查看进程详情：完整可执行文件路径、启动时间、命令行参数、数字签名状态、父进程 PID
- [ ] **PROC-07**: 进程 HANDLE 从 OpenProcess 获取后保留；绝不从存储的 PID 重新派生（PID 重用安全）

### 历史记录 (HIST)

- [ ] **HIST-01**: 应用记录端口占用变化（占用、释放、变更），含时间戳、端口号、协议、进程信息，存入 SQLite
- [ ] **HIST-02**: 用户可按端口号、PID、进程名或时间范围查询历史
- [ ] **HIST-03**: 历史记录在 TUI（Tab 3）和 GUI 中显示为可搜索时间线
- [ ] **HIST-04**: 旧历史条目自动清理以限制存储空间（可配置保留期限，默认 30 天）

### 流量监控 (TRAF)

- [ ] **TRAF-01**: 应用显示每端口和每进程的收发字节数
- [ ] **TRAF-02**: 流量统计在 TUI（Tab 4）中以表格+迷你趋势图显示；在 GUI 中以面板+速率图表显示
- [ ] **TRAF-03**: 流量计数器与端口列表共用 ETW/轮询刷新周期（几乎零额外开销）

### 防火墙 (FW)

- [ ] **FW-01**: 用户可查看 Windows 防火墙规则（可按入站/出站、允许/阻止、端口过滤）
- [ ] **FW-02**: 用户可创建新防火墙规则（名称、方向、动作、协议、本地端口、程序路径）
- [ ] **FW-03**: 用户可删除用户创建的防火墙规则
- [ ] **FW-04**: 用户可启用/禁用防火墙规则
- [ ] **FW-05**: 用户可右键端口 → "在防火墙中阻止此端口"或"在防火墙中放行此端口"—— 快捷操作使用合理默认值创建规则
- [ ] **FW-06**: 防火墙规则管理需要管理员权限；首次防火墙操作时提示提权

### 导出与数据 (EXP)

- [ ] **EXP-01**: 用户可导出当前端口列表为 JSON（结构化，供程序消费）
- [ ] **EXP-02**: 用户可导出当前端口列表为 CSV（电子表格兼容）
- [ ] **EXP-03**: 用户可复制选中行为制表符分隔文本到剪贴板

### 核心架构 (CORE)

- [ ] **CORE-01**: 共享 `port-core` Rust 库定义所有模型、trait 和平台抽象 —— 双前端共同消费
- [ ] **CORE-02**: 平台抽象通过 trait（PortScanner, ProcessManager, FirewallManager）实现，Windows 实现使用 `#[cfg(target_os = "windows")]`
- [ ] **CORE-03**: EventBus（tokio::sync::broadcast）解耦生产者（扫描器、ETW、进程管理器）和消费者（TUI Tab、GUI 面板、历史记录器）
- [ ] **CORE-04**: SQLite 数据库首次连接即启用 WAL 模式；schema 定义在 port-core 中供共享访问
- [ ] **CORE-05**: 配置（设置、白名单、标签、收藏、主题）以 TOML 文件存储在应用数据目录；支持热重载
- [ ] **CORE-06**: 工作区单体仓库：`port-core`（库）、`port-tui`（二进制）、`port-gui`（二进制）。单向依赖：前端依赖 core，绝不反向。

### 终端界面 (TUI)

- [ ] **TUI-01**: Tab 式 Widget Dashboard：[1] 概览、[2] 端口、[3] 历史、[4] 流量、[5] 防火墙
- [ ] **TUI-02**: 键盘优先导航：`1`-`5` 切换 Tab，`Tab`/`Shift+Tab` 循环面板，`/` 搜索，`?` 帮助浮层，`q` 退出
- [ ] **TUI-03**: Ratatui Elm Architecture (TEA)：集中式 Message 枚举、单一 update() 函数、每 Tab 的 Component trait
- [ ] **TUI-04**: 端口列表使用 VirtualTable（防止 1000+ 连接时滚动卡顿）
- [ ] **TUI-05**: 主题系统：模块化、可 serde 反序列化的主题文件（TOML）。`t` 键切换。预设：One Dark, Dracula, Solarized, Nord, Monokai, High Contrast
- [ ] **TUI-06**: 语言切换：`l` 键切换中英文。基于 fluent-i18n，模块化扩展点支持更多语言
- [ ] **TUI-07**: 最低 80x24 终端尺寸可用；调整大小时优雅降级；兼容 tmux/zellij/Windows Terminal
- [ ] **TUI-08**: 无闪烁渲染：双缓冲 + 批量写入 + 同步输出

### 桌面界面 (GUI)

- [ ] **GUI-01**: Tauri v2 桌面应用，Svelte 前端；响应式端口表格，支持排序/过滤/搜索
- [ ] **GUI-02**: 系统托盘：应用打开时托盘图标可见；关闭窗口时最小化到托盘或彻底退出（设置中配置）
- [ ] **GUI-03**: 左键托盘图标：弹出面板显示活跃端口列表+搜索；双击：打开主窗口；右键：设置/打开/退出菜单
- [ ] **GUI-04**: IPC 通过 Tauri 命令包装 port-core API；EventBus 事件通过 `AppHandle::emit` 转发到 Svelte stores
- [ ] **GUI-05**: 主题系统：与 TUI 主题匹配的预设，应用于 Svelte UI 和 Tauri 窗口边框
- [ ] **GUI-06**: 设置中切换语言；中英文界面

### 国际化 (I18N)

- [ ] **I18N-01**: 默认语言从系统区域自动检测；用户可在设置中覆盖
- [ ] **I18N-02**: 所有面向用户的字符串外置到 Fluent (FTL) 文件；添加语言 = 添加一个 FTL 文件目录
- [ ] **I18N-03**: TUI 和 GUI 共享相同的 FTL 源文件（在 port-core 中）

## 不做

| 功能 | 原因 |
|------|------|
| TCP 主动端口扫描（connect 探测） | 不同产品类别（nmap）。PortScanner trait 预留扩展点。 |
| 自动杀进程（watch 模式） | 共享机器上很危险。Watch+通知更安全；用户必须确认 kill。 |
| 原始数据包捕获/深度包检测 | 不同产品类别（Wireshark）。 |
| "Kill all" 按钮 | 系统不稳定风险。批量操作需要显式多选。 |
| 内置 HTTP 服务器用于远程访问 | 将管理员权限的本地工具暴露到网络存在安全风险。TUI 原生支持 SSH。 |
| 服务管理（启动/停止 Windows 服务） | 不同产品类别（services.msc）。仅显示关联服务名作为信息参考。 |
| 自动 DNS/WHOIS 查询每个连接 | 阻塞且慢。作为可选的右键操作提供。 |
| Linux/macOS 构建 | 平台抽象层已就位；具体实现延后。 |
| 移动端支持 | 不适用。 |
